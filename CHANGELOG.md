# Changelog

## 0.1.0 — experimental private prerelease

Initial Windows x64 delivery of Codex Launcher Awarness.

- Desktop Dashboard, Engines, Launch, Integration and History views, including labelled synthetic Demo mode.
- Shared timestamped evidence for CPU, RAM, configured storage, trusted NVIDIA probes, toolchain candidates, selected Python environments, local service health, WSL metadata and bounded project entry-point checks.
- Independent installation/configuration/reachability/readiness states with freshness, units, provenance and structured errors.
- Bounded Maxima version and four fixed mathematical checks with isolated user initialization; arbitrary build identifiers preserved without provenance claims.
- Exact context preview, immutable session artifacts, fixed JSON/PowerShell launch handoff, child-only optional Conda activation and duplicate-launch protection.
- Eleven read-only `cla_awareness` tools using the standard Python MCP SDK, with session integration and optional explicit managed persistent integration.
- Headless CLI, wheel/source packaging and separate GUI/CLI/MCP Windows portable entry points.
- Synthetic/unit/integration tests, dependency notices, build metadata and release verification scripts.

Artifact-specific test results, source commit, hashes and any blocked acceptance checks are recorded in the accompanying build/test manifests. This changelog is not evidence that every machine-specific or remote acceptance check passed.

Real Codex interactive launch, initial-context receipt and a model-driven awareness query remain **NOT_RUN / BLOCKED** for this prerelease; acceptance started **0 model calls**. Fake-Codex bootstrap checks, actual MCP protocol tests and synthetic GUI checks are reported separately. The default unelevated launch is blocked on the tested elevated-only desktop; the optional elevated live route was not exercised.

Known limits include no installer, no WSL launching, no embedded terminal, no automatic specialist bridge installation/handshake, no non-NVIDIA GPU telemetry and no framework execution check from package metadata alone. See the [roadmap](docs/roadmap.md). CLA source licensing remains pending before public distribution.
